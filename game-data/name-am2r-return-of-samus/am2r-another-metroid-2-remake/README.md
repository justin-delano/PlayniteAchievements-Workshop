# AM2R: Another Metroid 2 Remake

Custom/manual achievements for AM2R, a fanmade remake of Metroid II. Requires at least v1.4 of AM2R for the added game modes.
Most achievement progress can be checked on the main menu through the Gallery and the stats listed on save files.
