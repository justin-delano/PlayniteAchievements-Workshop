# Sonic 3 A.I.R.

Manual PlayniteAchievements set for Sonic 3 A.I.R. (Angel Island Revisited), a fanmade recompiled native PC port of Sonic the Hedgehog 3 & Knuckles.
All manual achievements and icons taken directly from Sonic 3 A.I.R.'s existing in-game achievements, with additional custom achievements for each playable character.
