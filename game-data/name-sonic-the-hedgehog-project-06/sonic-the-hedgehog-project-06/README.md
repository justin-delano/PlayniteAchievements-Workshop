# Sonic the Hedgehog: Project 06

Custom/manual achievements for Sonic: Project 06, a fanmade remake of Sonic the Hedgehog (2006).
Most achievement progress can be checked by viewing your rank result on the stage select screen.
Renders used for achievement icons created by ChaosX, the creator of Project 06.
