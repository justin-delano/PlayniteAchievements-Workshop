# Sonic 1 Forever

Manual PlayniteAchievements set for Sonic 1 Absolute, a fanmade recompiled native PC port of Sonic the Hedghehog released on Android with additional features.
All manual achievements and icons taken directly from Sonic 1 Forever's existing in-game achievements, with additional custom achievements for each playable character.
