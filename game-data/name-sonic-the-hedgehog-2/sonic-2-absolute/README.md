# Sonic 2 Absolute

Manual PlayniteAchievements set for Sonic 2 Absolute, a fanmade recompiled native PC port of the RetroEngine version of Sonic the Hedghehog 2 released on Android with additional features, created by Team Forever.
All manual achievements and icons taken directly from Sonic 2 Absolute's existing in-game achievements, with additional custom achievements for each playable character.
