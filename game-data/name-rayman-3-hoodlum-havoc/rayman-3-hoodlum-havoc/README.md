# Rayman 3: Hoodlum Havoc

Custom/Manual achievements for Rayman 3: Hoodlum Havoc, for those that prefer playing the original PC or GOG versions of Rayman 3 instead of using RetroAchievements compatible versions of the game.
Achievements primarily based on completion so progress can be checked through the in-game pause menu.
