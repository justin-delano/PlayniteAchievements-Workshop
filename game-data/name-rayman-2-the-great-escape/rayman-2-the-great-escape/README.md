# Rayman 2: The Great Escape

Custom/Manual achievements for Rayman 2: The Great Escape, for those that prefer playing the original PC or GOG versions of Rayman 2 instead of using RetroAchievements compatible versions of the game.
Achievements primarily based on completion so progress can be checked through the in-game level select or file select menu.
