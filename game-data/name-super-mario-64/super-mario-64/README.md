# Super Mario 64

Custom/Manual achievements for Super Mario 64 to be used on any of the fanmade PC ports of the Super Mario 64 decompilation, such as Render96, Super Mario 64 Plus, sm64coop, etc.
Most achievements based on level completion so that progression can be easily checked through the in-game pause menu.
