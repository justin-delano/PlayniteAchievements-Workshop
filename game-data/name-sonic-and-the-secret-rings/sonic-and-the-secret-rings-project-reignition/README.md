# Sonic and the Secret Rings (Project Reignition)

Manual PlayniteAchievement set for Sonic Project Reignition, a fanmade remake for Sonic and the Secret Rings.
Contains all achievements from the in-game achievement system, with additional achievements for unlocking the other extras in the Special Book.
