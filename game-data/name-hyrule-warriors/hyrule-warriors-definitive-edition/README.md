# Hyrule Warriors: Definitive Edition

Custom Nintendo Switch achievement set for Hyrule Warriors: Definitive Edition. Achievements are based on content exclusive to Hyrule Warriors Legends on the 3DS and Definitive Edition on Switch, and so can not be completed on the Wii U verison.
Achievement progress can be checked through the in-game Medals in the Gallery and completion percentages on the Adventure Mode menu.
